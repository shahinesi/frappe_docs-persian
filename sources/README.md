# Content source inventory

The current public portal is Wiki-backed. Public rendered pages expose an official Markdown representation using `<canonical-page-url>.md`, announced by `rel="alternate"` with type `text/markdown`. For example, `https://docs.frappe.io/insights/introduction.md` returns Markdown with frontmatter containing the title, space, canonical URL, and an `updated` date. This is the preferred retrieval path; the archived `frappe/frappe_docs` checkout is only historical Framework content.

The manifest records a per-page `.md` endpoint and its product/space. `source-repository` is left unset because no public authoring repository is asserted by the rendered page. `scripts/hydrate-source-metadata.mjs` retrieves each Markdown endpoint at a conservative concurrency, stores only metadata and a content digest, and never copies source prose into this repository. A missing endpoint is logged per page while the remaining pages continue.

Frappe's current [License and Trademark policy](https://docs.frappe.io/legal/others/license-and-trademark) says its documentation is under Creative Commons Attribution-ShareAlike (CC BY-SA), without specifying a version. It separately identifies product logos, icons, website content, marketing material, illustrations, graphics, and videos as protected Frappe intellectual property unless explicitly licensed otherwise. Therefore translated prose carries source attribution and a ShareAlike notice; images and branding are not copied into translations unless their individual license is verified. The archived `frappe_docs` MIT license covers that repository's software and does not override the current policy for live docs content.

Each source snapshot is retained only to support translation review and change detection. Before publishing a derivative, preserve attribution to the canonical page, mark it as an unofficial translation, and license the adaptation under the applicable CC BY-SA terms. The exact CC BY-SA version remains unspecified by the current policy and should not be guessed.
