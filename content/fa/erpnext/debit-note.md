شرکت Apex Components که تأمین‌کنندهٔ Nova Industries است، باتری تلفن تحویل داده؛ اما دو باتری آسیب‌دیده‌اند و باید برگشت داده شوند. Nova Industries باید بدهی خود به تأمین‌کننده را کاهش دهد، بی‌آنکه فاکتور خرید اصلی را تغییر دهد یا حذف کند.

بدهکار Note برگشت کالا یا اعتبار تأمین‌کننده را به‌صورت یک فاکتور خرید برگشتیِ جداگانه ثبت می‌کند. این سند آثار مربوط به بدهی، مالیات، هزینه و موجودی را معکوس می‌کند و در عین حال تراکنش اصلی را حفظ می‌کند.

وقتی کالا به تأمین‌کننده برگشت داده می‌شود، باید صورتحساب تأمین‌کننده کاهش یابد یا اعتبار تأمین‌کننده در برابر فاکتور خرید قبلی ثبت شود، از بدهکار Note استفاده کنید.

## پیش از شروع

به یک [فاکتور خرید](https://docs.frappe.io/erpnext/purchase-invoice) ثبت‌نهایی‌شده نیاز دارید. این موارد را تأیید کنید:

- کدام کالاها و چه تعداد از آن‌ها برگشت داده می‌شوند؛
- آیا ERPNext باید موجودی را نیز معکوس کند؛
- آیا رسید خرید پیوندخورده‌ای وجود دارد؛
- آیا مبلغ تأمین‌کننده قبلاً پرداخت شده است؛
- تاریخ ثبت مؤثری که برگشت باید از آن روز بر دفترها اثر بگذارد.

اگر فقط قیمت را اصلاح می‌کنید و کالا را نگه می‌دارید، [بدهکار Note برای تعدیل قیمت](debit-note-for-price-adjustment.md) را دنبال کنید.

## ایجاد بدهکار Note

1. فاکتور خرید ثبت‌نهایی‌شده‌ای را باز کنید که باید کاهش یابد.
2. **Create > Return / بدهکار Note** را انتخاب کنید.
3. ERPNext یک فاکتور خرید جدید می‌سازد که در آن **بازگشتی است (یادداشت بدهکاری)** فعال و **فاکتور برگشت در مقابل خرید** به صورتحساب اصلی پیوند داده شده است. پیش از تغییر کالاها، فعال‌بودن هر دو فیلد را بررسی کنید.
4. فقط کالاهایی را نگه دارید که برگشت داده می‌شوند؛ ردیف‌های بدون تغییر را حذف کنید.
5. تعداد برگشتی را به‌صورت عدد منفی وارد کنید. برای نمونه، برای برگشت دو واحد از مقدار اصلی ده، `-2` وارد کنید.
6. روی نماد مداد در ردیف کالا بزنید تا ویرایشگر کامل ردیف باز شود. تعداد برگشتی، نرخ اصلی، Warehouse، حساب هزینه، مرکز هزینه و ارجاع‌های سند مبدأ را بررسی کنید.
7. اگر برگشت باید موجودی را از انبار خارج کند، **به‌روزرسانی موجودی** را انتخاب و Warehouse را بررسی کنید. اگر موجودی قبلاً از طریق خرید Return در برابر رسید خرید برگشت داده شده، این گزینه را فعال نکنید.
8. مالیات‌ها و جمع‌ها را بررسی کنید. مبلغ‌های برگشتی باید منفی باشند.
9. بدهکار Note را ذخیره و ثبت نهایی کنید.

## بدهکار Note چه چیزهایی را به‌روز می‌کند؟

هنگام ثبت نهایی، ERPNext بدهی به تأمین‌کننده را کاهش می‌دهد و مقادیر مربوط به هزینه، دارایی، مالیات یا حساب تسویهٔ دریافت را معکوس می‌کند. اگر **به‌روزرسانی موجودی** انتخاب شده باشد، حرکت موجودی را نیز از Warehouse انتخاب‌شده خارج می‌کند.

فاکتور خرید اصلی همچنان ثبت‌نهایی‌شده باقی می‌ماند. مبلغ تسویه‌نشدهٔ آن با بدهکار Note کاهش می‌یابد. به‌این‌ترتیب، به‌جای بازنویسی صورتحساب اصلی، رد حسابرسی روشنی حفظ می‌شود.

اگر صورتحساب تأمین‌کننده پرداخت نشده باشد، بدهکار Note مبلغ قابل‌پرداخت را کاهش می‌دهد. اگر تأمین‌کننده قبلاً پرداخت شده باشد، ممکن است اعتبار تأمین‌کننده ایجاد شود که بتوان آن را به صورتحساب دیگری تخصیص داد یا با پرداخت تسویه کرد. اگر تخصیص‌ها به اصلاح نیاز دارند، از [تطبیق پرداخت](https://docs.frappe.io/erpnext/payment-reconciliation) استفاده کنید.

## فیلدهای مهم و کاربردشان

| فیلد | کاربرد |
| --- | --- |
| بازگشتی است (یادداشت بدهکاری) | فاکتور خرید را به‌عنوان برگشت مشخص می‌کند و مبلغ‌ها را به مقدارهای معکوس تغییر می‌دهد. |
| فاکتور برگشت در مقابل خرید | بدهکار Note را به صورتحساب اصلی پیوند می‌دهد و به‌روزرسانی مبلغ تسویه‌نشده و وضعیت سند را پشتیبانی می‌کند. |
| به‌روزرسانی معوق برای خود | مبلغ تسویه‌نشدهٔ خود بدهکار Note را حتی هنگام ارجاع به صورتحساب اصلی به‌روز می‌کند. اگر فرایند حسابداری شما اقتضای دیگری ندارد، مقدار پیش‌فرض را نگه دارید. |
| Update Billed مبلغ in سفارش خرید | در صورت کاربرد، مبلغ صورتحساب‌شده در سفارش خرید پیوندخورده را کاهش می‌دهد. |
| Update Billed مبلغ in رسید خرید | در صورت کاربرد، مبلغ صورتحساب‌شده در رسید خرید پیوندخورده را کاهش می‌دهد. |
| به‌روزرسانی موجودی | برگشت فیزیکی خرید را از طریق این سند در Warehouse ثبت می‌کند. |
| Items | اقلام برگشتی را مشخص می‌کند. تعداد و مبلغ معمولاً منفی‌اند. |
| تاریخ ارسال and Time | دورهٔ حسابداری و، در صورت استفاده، دورهٔ موجودی را برای برگشت تعیین می‌کند. |
| بستانکار To | حساب پرداختنی تأمین‌کننده است که بدهکار Note بر آن اثر می‌گذارد. |

## برگشت جزئی

می‌توانید کالاهای انتخابی یا فقط بخشی از تعداد یک کالا را برگردانید. نرخ اصلی را حفظ کنید، مگر اینکه بدهکار Note مشخصاً برای تعدیل قیمت باشد. ERPNext تعداد و مبلغ برگشت را به مقادیر قابل‌برگشت در سند مرجع محدود می‌کند.

برای نمونه، صورتحساب شامل ده تلفن به قیمت هرکدام 520 دلار است. اگر دو تلفن آسیب‌دیده برگشت داده شوند، مقدار `-2` را با نرخ `$520` وارد کنید. جمع بدهکار Note پیش از مالیات `$1,040` می‌شود و بدهی اصلی به همین میزان کاهش می‌یابد.

## ثبت نهایی و گام‌های بعدی

پس از ثبت نهایی:

- مبلغ تسویه‌نشدهٔ صورتحساب اصلی را بررسی کنید؛
- ماندهٔ تأمین‌کننده را در [حساب‌های پرداختنی](accounts-receivable-and-payable.md) بازبینی کنید؛
- ثبت‌های دفترکل را از مسیر **View > دفتر حسابداری** ببینید؛
- اگر **به‌روزرسانی موجودی** فعال بود، دفتر موجودی را بررسی کنید؛
- هر اعتبار باقیماندهٔ تأمین‌کننده را به فاکتور خرید یا پرداخت بعدی تخصیص دهید.

## وضعیت‌ها

| وضعیت | مفهوم |
| --- | --- |
| Draft | بدهکار Note هنوز بر دفترها اثر نگذاشته است. |
| Return | فاکتور خرید برگشتی ثبت نهایی شده است. |
| Unpaid | بدهکار Note ثبت نهایی شده، اما اعتبار تسویه‌نشده‌ای دارد که تخصیص نیافته است. |
| پرداخت شده | بدهکار Note به‌طور کامل تخصیص یا تسویه شده است. |
| Canceled | طبق قواعد لغو ERPNext، آثار حسابداری و موجودی آن معکوس شده‌اند. |

## عیب‌یابی

### تعداد برگشتی پذیرفته نمی‌شود

تأیید کنید تعداد منفی باشد، از مقدار باقیماندهٔ قابل‌برگشت بیشتر نباشد و به ردیف کالا اصلیِ درست ارجاع دهد.

### موجودی دو بار برگشت می‌خورد

برای یک حرکت فیزیکی، از یکی از این دو روش استفاده کنید: بدهکار Noteای که موجودی را به‌روز می‌کند، یا خرید Return در برابر رسید خرید. برای همان واحدهای برگشتی هر دو را ثبت نکنید.

### مبلغ تسویه‌نشدهٔ صورتحساب اصلی آن‌طور که انتظار می‌رود تغییر نکرده است

**فاکتور برگشت در مقابل خرید**، گزینهٔ به‌روزرسانی مبلغ تسویه‌نشده، پرداخت‌های موجود و تطبیق‌ها را بررسی کنید. سپس ورودی‌های دفتر پرداخت هر دو سند را بازبینی کنید.

### تأمین‌کننده قبلاً پرداخت شده است

بدهکار Note برای تأمین‌کننده اعتبار ایجاد می‌کند. آن را با صورتحساب بعدی تطبیق دهید یا مطابق فرایند خود، پرداخت بازپرداخت مناسب را ثبت کنید.

## پرسش‌های رایج

### آیا می‌توان بدون فاکتور خرید اصلی بدهکار Note ساخت؟

ERPNext در بعضی پیکربندی‌ها از برگشتِ بدون پیوند پشتیبانی می‌کند؛ اما پیوند به صورتحساب اصلی، اعتبارسنجی بهتر تعداد، به‌روزرسانی مبلغ تسویه‌نشده و شواهد حسابرسی را فراهم می‌کند. روش پیوندخورده را ترجیح دهید.

### آیا بدهکار Note می‌تواند فقط یک ردیف را برگرداند؟

بله. همهٔ ردیف‌های بدون تغییر را حذف کنید و فقط ردیف و تعداد برگشتی را نگه دارید.

### آیا هر بدهکار Note موجودی را به‌روز می‌کند؟

خیر. موجودی فقط زمانی تغییر می‌کند که سند برای به‌روزرسانی موجودی پیکربندی شده باشد. تعدیل صرفاً قیمتی نباید موجودی را جابه‌جا کند.
