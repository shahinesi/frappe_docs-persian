**Coupon Code** کدی را که مشتری در فروشگاه اینترنتی وارد می‌کند به یک [Pricing Rule مبتنی بر کد تخفیف](https://docs.frappe.io/erpnext/pricing-rule) پیوند می‌دهد. از آن برای ارائهٔ تخفیفی کنترل‌شده با کد تبلیغاتی یا کدی شبیه کارت هدیهٔ اختصاصی مشتری استفاده کنید.

## پیش از شروع

بررسی کنید که:

- فروشگاه اینترنتی ERPNext پیکربندی شده باشد.
- ورود کد تخفیف در [E-commerce Settings](https://docs.frappe.io/erpnext/e-commerce-settings) فعال باشد.
- [کالاهای](item.md) مشمول و قیمت‌های آن‌ها به‌صورت آنلاین در دسترس باشند.
- یک Selling Pricing Rule ساخته باشید که گزینهٔ **Coupon Code Based** در آن فعال است.

خود Coupon Code تخفیف را تعریف نمی‌کند؛ Pricing Rule پیوندخورده شرایط واجدبودن و تخفیف قیمت یا محصول را تعیین می‌کند.

## ایجاد Pricing Rule مبتنی بر کد تخفیف

1. **Pricing Rule** را باز کنید و **Add Pricing Rule** را انتخاب کنید.
2. کالاها و گروه‌های کالای مشمول، شرط‌های تراکنش، محدودیت تعداد یا مبلغ و بازهٔ اعتبار را تنظیم کنید.
3. **Price Discount** یا **Product Discount** را انتخاب کنید.
4. **Coupon Code Based** را فعال کنید.
5. قاعده را ذخیره کنید.

از هم‌پوشانی قاعده‌های تخفیف پرهیز کنید، مگر آنکه اولویت موردنظرشان را آزمایش کرده باشید.

## ایجاد Coupon Code

1. فهرست **Coupon Code** را باز و **Add Coupon Code** را انتخاب کنید.
2. نام کوپن را وارد کنید.
3. **Coupon Type** را انتخاب کنید:
   - **Promotional:** کدی قابل‌استفادهٔ مجدد می‌سازد که از نام کوپن گرفته می‌شود.
   - **Gift Card:** کدی تصادفی تولید می‌کند که برای توزیع کنترل‌شده‌تر در نظر گرفته شده است.
4. Pricing Rule مبتنی بر کد تخفیف را انتخاب کنید.
5. مقدارهای **Valid From** و **Valid Upto** را تنظیم کنید.
6. اگر باید تعداد کل استفاده‌ها محدود شود، **Maximum Use** را تعیین کنید.
7. توضیحی وارد کنید که بتوان آن را در پیام‌های کمپین به‌کار برد.
8. ذخیره کنید.

Coupon Code تولیدشده یکتا و فقط‌خواندنی است. پیش از فرستادن محتوای کمپین، آن را بررسی کنید.

## استفاده از Coupon Code

خریدار می‌تواند کد را در فیلد کوپن فروشگاه اینترنتی وارد کند. پس از اعتبارسنجی کد و قاعدهٔ پیوندخورده در ERPNext، قیمت‌های مشمول دوباره محاسبه می‌شوند.

پیوند کمپین می‌تواند پارامتر کوپن هم داشته باشد:

```text
https://shop.example.com/products/aerobook-14?cc=SUMMER20
```

فقط از نشانی‌هایی استفاده کنید که پیاده‌سازی فعلی فروشگاه اینترنتی شما پشتیبانی می‌کند و پیش از انتشار، مسیر کامل خرید مشتری را آزمایش کنید.

## استفاده و اعتبار

| فیلد | آنچه کنترل می‌کند |
| --- | --- |
| Coupon Type | تبلیغاتی‌بودن کد یا تصادفی‌بودن آن را تعیین می‌کند. |
| Pricing Rule | تخفیف و شرط‌های واجدبودن را مشخص می‌کند. |
| Valid From / Valid Upto | بازهٔ استفاده از کد را تعیین می‌کند. |
| Maximum Use | تعداد کل دفعات مجاز استفاده را محدود می‌کند. |
| Used | تعداد سفارش فروشهای ثبت‌شده‌ای که از کوپن استفاده کرده‌اند. |
| Coupon Code Description | متن پشتیبان کمپین یا ایمیل را نگه می‌دارد. |

شمارندهٔ **Used** با ثبت سفارش‌های واجدشرایط افزایش می‌یابد. لغو یا اصلاح تراکنش‌ها ممکن است تفسیر عملی این عدد را پیچیده کند؛ اگر مقدار استفاده غیرمنتظره است، اسناد فروش پیوندخورده را بررسی کنید.

## آزمایش پیش از انتشار

دست‌کم این موارد را آزمایش کنید:

- کالا و تعداد واجدشرایط؛
- کالای غیرمشمول؛
- تاریخ‌های پیش از اعتبار، در طول اعتبار و پس از آن؛
- مرز تعداد مجاز استفاده؛
- تسویه‌حساب کاربر واردشده و مهمان، اگر هر دو پشتیبانی می‌شوند؛
- [راهنمای «Create Promotional Schemes and Discount Slabs | ERPNext Documentation» در ERPNext](https://docs.frappe.io/erpnext/promotional-scheme) یا تخفیف خودکار دیگری که ممکن است با این کوپن هم‌پوشانی داشته باشد.

## عیب‌یابی

| مشکل | موردی که باید بررسی شود |
| --- | --- |
| فیلد کوپن وجود ندارد | ورود کد تخفیف را در E-commerce Settings فعال کنید. |
| کد رد می‌شود | املای کد، اعتبار، سقف استفاده و Pricing Rule پیوندخورده را بررسی کنید. |
| کد تخفیفی اعمال نمی‌کند | مطمئن شوید سبد خرید همهٔ شرط‌های Pricing Rule را دارد. |
| تخفیف نادرست اعمال می‌شود | هم‌پوشانی و اولویت Pricing Ruleها را بررسی کنید. |
| مقدار Used غیرمنتظره است | سفارش فروشهای ثبت‌شده‌ای را که کوپن دارند بررسی کنید. |

## پرسش‌های متداول

### آیا می‌توان از Coupon Code در تراکنش‌های فروش میزکار استفاده کرد؟

Coupon Code برای جریان کار فروشگاه اینترنتی طراحی شده است. برای تراکنش‌های میزکار مستقیماً از Pricing Rule استفاده کنید.

### آیا Coupon Code از نوع Gift Card ابزار پرداخت با ارزش ذخیره‌شده است؟

خیر. در این قابلیت، کدی تولیدشده و پیوندخورده به Pricing Rule است، نه کیف پول مالی.

### آیا می‌توان یک Coupon Code را به چند Pricing Rule پیوند داد؟

هر Coupon Code به یک Pricing Rule پیوند می‌خورد. برای تعریف پیشنهاد از شرط‌های همان قاعده استفاده کنید.

### آیا می‌توان استفاده را به یک‌بار برای هر مشتری محدود کرد؟

**Maximum Use** تعداد استفادهٔ کلی را محدود می‌کند. بررسی کنید جریان کار فعلی فروشگاه اینترنتی شما محدودیت اختصاصی هر مشتری را که لازم دارید اعمال می‌کند یا نه.
