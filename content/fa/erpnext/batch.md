> از نسخهٔ 15 به بعد، امکان «موجودی منفی مجاز است» برای کالاهای سریال‌دار یا دارای Batch برداشته شده است. بنابراین حتی اگر این گزینه در Stock Settings فعال باشد، از نسخهٔ 15 نمی‌توان برای این کالاها تراکنشی با موجودی منفی ثبت کرد.

برای فعال‌کردن قابلیت سریال/Batch برای کالا، ابتدا گزینهٔ «Enable Serial and Batch No for Item» را در «Stock Settings» علامت بزنید.

![](https://docs.frappe.io/files/Screenshot%202026-03-06%20at%2011.52.18%20AM.png)

**قابلیت Batch در ERPNext به شما امکان می‌دهد چند واحد از یک کالا را گروه‌بندی کنید و به آن‌ها مقدار، شماره یا برچسب یکتایی با عنوان Batch No اختصاص دهید.**

Batch بر اساس کالا تعریف می‌شود. اگر کالا دارای Batch باشد، باید در هر تراکنش موجودی شمارهٔ Batch آن ذکر شود. شماره‌های Batch را می‌توان دستی یا خودکار نگهداری کرد. این قابلیت برای تعیین تاریخ انقضای چند کالا یا انتقال هم‌زمان آن‌ها به انبارهای دیگر مفید است.

برای دسترسی به فهرست Batch No، به این مسیر بروید:

> خانه > انبار > شمارهٔ سریال و Batch > Batch

## 1. پیش‌نیازها

پیش از ایجاد و استفاده از Batch، بهتر است ابتدا موارد زیر را آماده کنید:

- [کالا](item.md)
- گزینهٔ «Has Batch No» را در رکورد اصلی کالا فعال کنید.

![فعال‌بودن گزینهٔ Batch No](https://docs.frappe.io/files/batch-no-enabled.png)

## 2. ایجاد Batch جدید

برای اینکه یک کالا از Batch استفاده کند، باید فیلد «Has Batch No» در رکورد اصلی کالا فعال باشد. اگر هنگام ایجاد کالا گزینهٔ «Automatically Create New Batch» را انتخاب نکرده‌اید، باید هنگام نیاز Batchها را دستی ایجاد کنید.

برای ایجاد رکورد اصلی Batch No برای یک کالا:

1. به فهرست Batch بروید و روی «جدید» کلیک کنید.
2. Batch ID را تعیین کنید.
3. کالا را انتخاب کنید.
4. اگر برای کالا تراکنشی انجام شده باشد، دیگر نمی‌توان Batch آن را فعال یا غیرفعال کرد.
5. ذخیره کنید.

وقتی Batch برای کالا فعال باشد، گزینهٔ [نگهداری موجودی نمونه](https://docs.frappe.io/erpnext/retain-sample-stock) نیز در دسترس قرار می‌گیرد.

### 2.1 ایجاد خودکار Batch

اگر می‌خواهید Batch هنگام ثبت رسید خرید به‌طور خودکار ایجاد شود، گزینهٔ «Automatically Create New Batch» را در رکورد اصلی کالا فعال کنید.

![تنظیم کالا برای استفاده از Batch](https://docs.frappe.io/files/item_setup_for_batch.png)

## 3. قابلیت‌ها

### 3.1 تقسیم و جابه‌جایی Batchها

وقتی Batch را باز می‌کنید، همهٔ مقدارهای متعلق به آن Batch در صفحه نمایش داده می‌شوند.

![نمای Batch](https://docs.frappe.io/files/batch_view.png)

- برای انتقال Batch از یک انبار به انبار دیگر، روی دکمهٔ **Move** کلیک کنید.
- برای تقسیم Batch به چند Batch کوچک‌تر، روی **Split** کلیک کنید. Batch جدیدی بر اساس Batch فعلی ساخته می‌شود و مقدارها میان Batchها تقسیم خواهند شد.

![تقسیم Batch](https://docs.frappe.io/files/batch_split.png)

اگر تاریخ انقضا را تعیین کنید، وضعیت Batch تا پیش از آن تاریخ «منقضی‌نشده» و پس از آن «منقضی‌شده» خواهد بود. اگر تاریخی تعیین نشود، وضعیت «تنظیم‌نشده» نمایش داده می‌شود.

### 3.2 ثبت تراکنش برای کالاهای دارای Batch

رکورد اصلی Batch باید پیش از ایجاد رسید خرید ساخته شود. بنابراین هر بار که برای کالای Batchدار رسید خرید یا دستور کار ایجاد می‌کنید، ابتدا Batch No آن را بسازید و سپس در سفارش خرید یا Stock Entry انتخاب کنید.

در هر تراکنش موجودی (رسید خرید، یادداشت تحویل یا فاکتور) برای کالای Batchدار، باید Batch No کالا را وارد کنید.

> توجه: در تراکنش‌های موجودی، Batch IDها بر اساس کد کالا، انبار، تاریخ انقضای Batch (در مقایسه با تاریخ ثبت تراکنش) و مقدار واقعی موجودی در انبار فیلتر می‌شوند. اگر Batch ID را بدون مقداردهی فیلد انبار جست‌وجو کنید، فیلتر مقدار واقعی اعمال نمی‌شود.
