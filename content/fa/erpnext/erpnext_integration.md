> این صفحه ترجمهٔ غیررسمی مستندات ERPNext است. [مشاهدهٔ منبع اصلی](https://docs.frappe.io/erpnext/erpnext_integration)
> طبق [سیاست رسمی مجوز و علامت تجاری Frappe](https://docs.frappe.io/legal/others/license-and-trademark)، مستندات تحت شرایط CC BY-SA هستند. این ترجمه با انتساب به منبع بازنشر می‌شود؛ نسخهٔ مجوز در سیاست مشخص نشده است.

ERPNext قابلیت‌های متنوعی برای یکپارچه‌سازی دارد و به کسب‌وکارها کمک می‌کند برنامه‌ها و سرویس‌های گوناگون شخص ثالث را به‌سادگی متصل کنند تا کارایی عملیاتی و جریان داده بهبود یابد.

این یکپارچه‌سازی‌ها پلتفرم‌های فروش اینترنتی، درگاه‌های پرداخت، ارائه‌دهندگان خدمات ارسال، سرویس‌های Google و موارد دیگر را در بر می‌گیرند. با اتصال ERPNext به این سامانه‌ها، کسب‌وکارها می‌توانند فرایندها را ساده کنند، ورود دستی داده را کاهش دهند، دقت داده‌ها را افزایش دهند و شناخت عمیق‌تری از عملیات خود به‌دست آورند تا تصمیم‌های آگاهانه‌تری بگیرند.

برای اتصال ERPNext به برنامه‌هایی که در فهرست زیر نیامده‌اند، می‌توانید از REST API فریم‌ورک Frappe استفاده کنید. برای آشنایی بیشتر، [راهنمای REST API فریم‌ورک Frappe](https://frappeframework.com/docs/user/en/guides/integration/rest_api) را ببینید.
