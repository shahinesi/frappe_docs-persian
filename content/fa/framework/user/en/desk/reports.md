## Frappe Framework چیست؟

Frappe (با تلفظ «فراپِی») یک فریم‌ورک وب تمام‌پشته است که با Python و JavaScript نوشته شده و همهٔ اجزای لازم برای ساخت برنامه‌های وب را در اختیار می‌گذارد. پایگاه دادهٔ آن MariaDB است. این فریم‌ورک زیربنای [ERPNext](https://erpnext.com) است و کاربرد عمومی دارد؛ بنابراین می‌توان با آن برنامه‌های داده‌محور ساخت.

## چرا Frappe؟

تفاوت اصلی Frappe با بسیاری از فریم‌ورک‌ها این است که فراداده نیز مانند داده در نظر گرفته می‌شود. این رویکرد ساخت رابط‌های کاربری را آسان می‌کند. Frappe از معماری یکپارچه پیروی می‌کند و تقریباً همهٔ امکانات لازم برای ساخت برنامهٔ وب امروزی را یک‌جا فراهم می‌آورد. رابط مدیریتی کامل آن، **پیشخوان**، از ابتدا فرم‌ها، پیمایش، فهرست‌ها، منوها، مجوزها، پیوست فایل و امکانات دیگر را مدیریت می‌کند. برای آشنایی بیشتر، [چرا Frappe Framework؟](../basics/why.md) را بخوانید.

## ویژگی‌های اصلی

1. **فریم‌ورک تمام‌پشته:** توسعهٔ سمت کاربر و سمت سرور را پوشش می‌دهد و به توسعه‌دهندگان امکان می‌دهد با یک فریم‌ورک برنامه‌های کامل بسازند.
2. **رابط مدیریتی آماده:** پیشخوانی قابل‌سفارشی‌سازی برای مدیریت داده‌های برنامه فراهم می‌کند و زمان و تلاش توسعه را کاهش می‌دهد.
3. **مجوزهای مبتنی بر نقش:** سامانه‌ای جامع برای مدیریت کاربران و نقش‌ها دارد تا دسترسی‌ها و مجوزهای برنامه را کنترل کنید.
4. **REST API:** برای همهٔ مدل‌ها به‌طور خودکار API سازگار با REST می‌سازد تا اتصال به سامانه‌ها و سرویس‌های دیگر آسان باشد.
5. **فرم‌ها و نماهای قابل‌سفارشی‌سازی:** می‌توان فرم‌ها و نماها را با اسکریپت سمت سرور و JavaScript سمت کاربر تغییر داد.
6. **گزارش‌ساز:** ابزاری توانمند برای ساخت گزارش‌های سفارشی، بدون نیاز به نوشتن کد.

## نصب

برای استفاده از Frappe ابتدا باید آن را نصب کنید. [راهنمای نصب Frappe](https://docs.frappe.io/framework/user/en/installation) روش‌های مختلف نصب را توضیح می‌دهد و به آشنایی با پشتهٔ سمت سرور نیز کمک می‌کند.

## یادگیری و جامعهٔ کاربری

1. [مدرسهٔ Frappe](https://school.frappe.io/lms/courses): دوره‌های گوناگون Frappe Framework و ERPNext را از نگه‌دارندگان پروژه یا جامعهٔ کاربری دنبال کنید.
2. [مخزن Frappe در GitHub](https://github.com/frappe/frappe): کد منبع را ببینید، مشارکت کنید و با جامعهٔ Frappe همکاری داشته باشید.
3. [انجمن گفت‌وگو](https://discuss.frappe.io/c/framework/5): در انجمن رو‌به‌رشد پروژه پرسش بپرسید، به دیگران کمک کنید و در گفت‌وگوها شرکت کنید.
4. [Build with Hussain](https://youtube.com/@buildwithhussain): نمونه‌های کاربرد Frappe Framework برای ساخت برنامه‌های وب حرفه‌ای را تماشا کنید.
