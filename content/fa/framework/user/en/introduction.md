## Frappe Framework چیست؟

Frappe (با تلفظ *فِرِی‌پِی*) یک فریم‌ورک وب تمام‌پشته و مجهز به امکانات موردنیاز است که با Python و JavaScript نوشته شده و از MariaDB به‌عنوان پایگاه داده استفاده می‌کند. ERPNext بر پایهٔ این فریم‌ورک ساخته شده است. Frappe کاربرد عمومی دارد و می‌توان با آن برنامه‌های مبتنی بر پایگاه داده ساخت.

## چرا Frappe؟

تفاوت اصلی Frappe با فریم‌ورک‌های دیگر این است که فراداده (metadata) نیز مانند داده با آن رفتار می‌شود. این ویژگی ساخت آسان رابط‌های کاربری را ممکن می‌کند. Frappe بر پایهٔ معماری یکپارچه (monolithic) طراحی شده و تقریباً همهٔ امکانات لازم برای ساخت یک برنامهٔ وب مدرن را در اختیار شما می‌گذارد. رابط مدیریتی کامل آن، یعنی Desk، فرم‌ها، پیمایش، فهرست‌ها، منوها، مجوزها، پیوست فایل و امکانات دیگری را از ابتدا فراهم می‌کند. برای اطلاعات بیشتر، راهنمای مستندات Frappe را بخوانید.

## قابلیت‌های کلیدی

1. **فریم‌ورک تمام‌پشته:** Frappe توسعهٔ بخش کارخواه (front-end) و کارساز (back-end) را پوشش می‌دهد و به توسعه‌دهندگان اجازه می‌دهد با یک فریم‌ورک برنامه‌های کامل بسازند.
2. **رابط مدیریتی داخلی:** یک داشبورد مدیریتی آماده و قابل‌سفارشی‌سازی برای مدیریت داده‌های برنامه فراهم می‌کند و زمان و تلاش لازم برای توسعه را کاهش می‌دهد.
3. **مجوزهای مبتنی بر نقش:** مدیریت جامع کاربران و نقش‌ها برای کنترل دسترسی و مجوزهای برنامه.
4. **REST API:** برای همهٔ مدل‌ها API سازگار با REST به‌صورت خودکار ساخته می‌شود تا اتصال به سامانه‌ها و سرویس‌های دیگر آسان باشد.
5. **فرم‌ها و نماهای قابل‌سفارشی‌سازی:** فرم‌ها و نماها را می‌توان با اسکریپت سمت کارساز و JavaScript سمت کارخواه به‌صورت انعطاف‌پذیر سفارشی کرد.
6. **سازندهٔ گزارش:** ابزار قدرتمندی برای ساخت گزارش‌های سفارشی، بدون نیاز به نوشتن کد.
