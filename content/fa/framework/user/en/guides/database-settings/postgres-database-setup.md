برای استفاده از Postgres به‌عنوان پایگاه دادهٔ سایت تازه، فرمان زیر را اجرا کنید:

```sh
bench new-site <site-name> --db-type postgres
```

**نکته:** مطمئن شوید نسخهٔ 9 یا جدیدتر Postgres روی سامانه نصب باشد.
