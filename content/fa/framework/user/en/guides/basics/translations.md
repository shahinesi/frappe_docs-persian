# افزودن و مدیریت ترجمه‌ها در برنامهٔ سفارشی Frappe: راهنمای گام‌به‌گام

## 1. ساخت پوشهٔ `translations`

**گام:**

در پوشهٔ برنامهٔ سفارشی خود، پوشه‌ای به نام `translations` در مسیر زیر بسازید:

```text
apps/your-app/your-app/translations/
```

**دلیل:**

Frappe این پوشه را به‌طور خودکار پیدا می‌کند. این روش از قرارداد به‌جای پیکربندی پیروی می‌کند؛ بنابراین با قرار دادن فایل‌های ترجمه در این مسیر، بدون تنظیم اضافه شناسایی می‌شوند.

## 2. افزودن فایل‌های CSV ترجمه

**گام:**

برای هر زبان، یک فایل CSV در پوشهٔ `translations` بسازید. برای نمونه:

- `ar.csv` (عربی)
- `es.csv` (اسپانیایی)

**ساختار CSV:**

```csv
"source_string","translated_string","context"
"agent","توكيل",""
"continue","إستكمال",""
```

**دلیل:**

- ستون اول (`source_string`): رشتهٔ اصلی در کد، مانند `_("continue")`.
- ستون دوم (`translated_string`): برگردان رشته.
- ستون سوم (`context`): اختیاری است و برای روشن‌کردن بافت ترجمه به‌کار می‌رود.

می‌توانید ستون سوم را خالی بگذارید.

## 3. نشانه‌گذاری رشته‌های ترجمه‌پذیر در کد

**گام:**

رشته‌ها را در کد Python، HTML یا JavaScript با تابع `_()` مشخص کنید:

```python
from frappe import _

def my_function():
    message = _("continue")  # برای کاربران عربی با «إستكمال» جایگزین می‌شود
```

**دلیل:**

تابع `_()` مشخص می‌کند که رشته باید ترجمه شود. هنگام اجرا، Frappe آن را بر اساس زبان ترجیحی کاربر جایگزین می‌کند.

## 4. ساخت سایت

این مرحله فقط زمانی لازم است که در JavaScript سفارشیِ سمت کارخواه از `__()` استفاده کرده باشید و فایل‌های JavaScript را تغییر داده باشید.

**گام:**

فرمان ساخت را اجرا کنید:

```shell
bench --site your-site build
```

## 5. بررسی ترجمه‌ها

**گام:**

- زبان کاربر را در Frappe به عربی یا زبان مقصد تغییر دهید.
- بررسی کنید که `_("continue")` اکنون به‌صورت `"إستكمال"` نمایش داده می‌شود.

**دلیل:**

این بررسی تأیید می‌کند که Frappe رشتهٔ اصلی را به برگردان متناظر نگاشت می‌کند.

## نکته‌های مهم

### کد زبان

- نام فایل CSV باید با کد زبان Frappe مطابقت داشته باشد؛ برای نمونه، `ar` برای عربی.
- این کدها را می‌توانید در **Frappe ← تنظیمات زبان** پیدا کنید.

### محل پوشه

پوشهٔ `translations` باید در ریشهٔ بستهٔ برنامه باشد، نه درون یکی از زیرماژول‌ها.

### کارایی

- ترجمه‌ها هنگام ساخت، در حافظهٔ پنهان قرار می‌گیرند.
- پس از ویرایش فایل‌های ترجمه، همیشه Bench را دوباره راه‌اندازی کنید.

### رفتار جایگزین

اگر رشته‌ای ترجمه نشده باشد، Frappe از رشتهٔ اصلی استفاده می‌کند.

## آیا لازم است سایت را بسازم یا مهاجرت بدهم؟

**خیر.** Frappe ترجمه‌ها را به‌صورت پویا و هنگام اجرا از فایل `translations/lang.csv` بارگذاری می‌کند و زبان ترجیحی کاربرِ واردشده را در نظر می‌گیرد. فقط لازم است صفحهٔ مرورگر را تازه‌سازی کنید یا در صورت نیاز حافظهٔ پنهان را پاک کنید.

فرمان `bench build` فقط وقتی لازم است که در JavaScript سفارشیِ سمت کارخواه از `__()` استفاده کرده باشید و فایل‌های JavaScript را تغییر داده باشید.

## نمونهٔ گردش کار

1. فایل زیر را بسازید:

   ```text
   apps/my_app/my_app/translations/ar.csv
   ```

2. یک ردیف ترجمه اضافه کنید:

   ```csv
   "welcome_message","مرحبا بك!",""
   ```

3. رشته را در کد به‌کار ببرید:

   ```python
   _("welcome_message")
   ```

4. حافظهٔ پنهان را پاک کنید؛ اگر ترجمه بی‌درنگ دیده نمی‌شود از این فرمان استفاده کنید:

   ```shell
   bench --site my-site clear-cache
   ```

5. سایت را بسازید؛ این مرحله فقط در صورت تغییر JavaScript سفارشیِ سمت کارخواه که از `__()` استفاده می‌کند لازم است:

   ```shell
   bench --site my-site build
   ```

6. رابط عربی را بررسی کنید.

## منظور از بافت چیست؟

بافت، فراداده‌ای است که به استفاده‌کننده می‌گوید ترجمه را کجا و در چه موقعیتی به‌کار ببرد؛ چون یک واژه ممکن است معناهای متفاوتی داشته باشد.

برای نمونه، واژهٔ `charge` می‌تواند دو معنای متفاوت داشته باشد:

```csv
"charge","شحن",""
"charge","رسوم",""
```

در اینجا یک رشته با دو معنای متفاوت داریم. برای تشخیص مورد درست، باید بافت را تعیین کنیم:

```csv
"charge","شحن","mobile phone charge"
"charge","رسوم","invoice line"
```

در کد:

```python
_("charge")  # بدون بافت، منظور مشخص نیست
_("charge", context="mobile phone charge")  # منظور «شحن» است
_("charge", context="invoice line")  # منظور «رسوم» است
```

> **یادداشت مترجم:** این راهنما دربارهٔ بارگذاری پویا و کش ترجمه‌ها توضیح‌های ناسازگار دارد. روش مدیریت ترجمه به نسخهٔ Frappe و قالب فایل وابسته است؛ مستندات جاری، برای نسخه‌های تا v15 فایل‌های CSV و برای v16 به بعد قالب PO را شرح می‌دهد. پیش از استقرار، [ترجمه ها](https://docs.frappe.io/framework/user/en/translations) و [فرمان‌های ترجمهٔ Bench](https://docs.frappe.io/framework/user/en/bench/frappe-commands) را برای نسخهٔ نصب‌شده بررسی کنید.
