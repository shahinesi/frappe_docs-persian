نوع سند **اعلان** در Frappe Framework راهی برای خودکارسازی اعلان‌ها در کانال‌های گوناگون، هنگام رخ‌دادن رویدادهای مشخص در سامانه، فراهم می‌کند. در این راهنما تنظیم و استفادهٔ مؤثر از اعلان‌ها را می‌آموزید.

## تنظیمات عمومی

- **فعال:** اعلان را فعال یا غیرفعال می‌کند.
- **کانال:** روش ارسال اعلان را انتخاب کنید:
  - **ایمیل:** ارسال اعلان از راه ایمیل
  - **Slack:** ارسال اعلان به یک کانال Slack
  - **اعلان سامانه:** نمایش اعلان در رابط Frappe
  - **پیامک:** ارسال اعلان با پیامک؛ باید تنظیمات پیامک را پیکربندی کرده باشید.
- **استاندارد است:** در حالت توسعه، مشخص می‌کند اعلان بخشی از یک ماژول استاندارد باشد.

## رویدادهای آغازگر

اعلان‌ها می‌توانند بر اساس رویدادهای مختلف اجرا شوند.

### رویدادهای سند

- **جدید:** هنگام ایجاد سند تازه اجرا می‌شود.
- **ذخیره:** هنگام ذخیرهٔ سند اجرا می‌شود.
- **ثبت نهایی:** هنگام ثبت نهایی سند اجرا می‌شود.
- **لغو:** هنگام لغو سند اجرا می‌شود.

### رویدادهای مبتنی بر تاریخ

- **چند روز پیش از تاریخ:** به تعداد روز مشخص، پیش از مقدار یک فیلد تاریخ اجرا می‌شود.
- **چند روز پس از تاریخ:** به تعداد روز مشخص، پس از مقدار یک فیلد تاریخ اجرا می‌شود.
- هنگام استفاده از این رویدادها:
  - **تاریخ مرجع:** فیلد تاریخی را که باید بررسی شود انتخاب کنید.
  - **چند روز پیش یا پس از تاریخ:** تعداد روزهای فاصله تا تاریخ را تعیین کنید.

### رویدادهای مبتنی بر مقدار

- **تغییر مقدار:** وقتی مقدار یک فیلد مشخص تغییر کند اجرا می‌شود.
  - **مقدار تغییرکرده:** فیلدی را که باید تغییراتش بررسی شود انتخاب کنید.

### رویدادهای مبتنی بر متد

- **متد:** هنگامی اجرا می‌شود که متد مشخصی از سند فراخوانی شود.
  - **متد آغازگر:** نام متد را وارد کنید؛ برای نمونه `before_insert` یا `after_update`.

### رویدادهای سفارشی

- **سفارشی:** برای اعلان‌هایی است که به‌صورت برنامه‌نویسی آغاز می‌شوند.

## آغازگرهای شرطی

برای محدودکردن اعلان به موقعیت‌های مناسب، شرط اضافه کنید:

- **شرط:** عبارت Python که باید مقدار `True` داشته باشد تا اعلان ارسال شود.
- شرط به این موارد دسترسی دارد:
  - `doc`: سندی که رویداد اعلان را آغاز کرده است.
  - `nowdate()`: تابع تاریخ جاری.
  - `frappe.utils`: توابع کمکی.

### نمونه‌ها

- وضعیت سند «باز» باشد:

    ```python
    doc.status=="Open"
    ```

- **سررسید** سند با تاریخ جاری برابر باشد:

    ```python
    doc.due_date==nowdate()
    ```

- جمع کل بیشتر از 40000 باشد:

    ```python
    doc.total > 40000
    ```

## تنظیم گیرندگان

### کانال‌های ایمیل، اعلان سامانه و پیامک

گیرندگان را در جدول گیرندگان تنظیم کنید:

1. **نوع گیرنده:**
   - **بر اساس فیلد سند:** فیلدی را انتخاب کنید که نشانی ایمیل یا شمارهٔ تلفن را در بر دارد.
   - **بر اساس نقش:** نقشی را انتخاب کنید تا اعلان برای کاربران دارای آن نقش ارسال شود.
   - **سفارشی:** گیرندگان دلخواه را مشخص کنید.
2. **گزینه‌های بیشتر:**
   - **رونوشت/رونوشت مخفی:** برای اعلان‌های ایمیلی
   - **شرط:** عبارت Python برای افزودن مشروط گیرنده
   - **ارسال به همهٔ مسئولان:** همهٔ کاربرانی را که به سند تخصیص یافته‌اند اضافه می‌کند.

### کانال Slack

از فهرست کشویی، نشانی URL ازپیش‌تعریف‌شدهٔ وب‌هوک Slack را انتخاب کنید.

## تنظیم پیام

### موضوع (برای ایمیل، Slack و اعلان سامانه)

- متن موضوع را وارد کنید.
- الگوهای Jinja پشتیبانی می‌شوند؛ برای نمونه: `{{ doc.name }} Delivered`

### متن پیام

- **نوع پیام:** یکی از HTML، Markdown یا متن ساده را انتخاب کنید. گزینهٔ متن ساده فقط در حالت توسعه در دسترس است.
- **پیام:** محتوای اعلان را وارد کنید.
- برای درج محتوای پویا از الگوهای Jinja استفاده می‌شود.

### متغیرهای الگو

- `{{ doc }}`: دسترسی به هر فیلد سند آغازگر؛ برای نمونه `{{ doc.customer }}`.
- `{{ comments }}`: دسترسی به دیدگاه‌های سند؛ برای نمونه `{{ comments[-1].comment }}`.
- `{% if %}...{% endif %}`: منطق شرطی
- `{{ nowdate() }}`: تاریخ جاری

### نمونهٔ الگو

```html
<h3>Order Overdue</h3>

<p>Transaction {{ doc.name }} has exceeded Due Date. Please take necessary action.</p>

<!-- show last comment -->
{% if comments %}
Last comment: {{ comments[-1].comment }} by {{ comments[-1].by }}
{% endif %}

<h4>Details</h4>

<ul>
<li>Customer: {{ doc.customer }}
</li><li>Amount: {{ doc.grand_total }}
</li></ul>
```

## گزینه‌های پیشرفته

### تنظیمات پیوست

- **پیوست چاپی:** نسخهٔ PDF چاپی سند را پیوست می‌کند.
  - **قالب چاپ:** قالب چاپ مشخصی را برای PDF پیوست‌شده انتخاب کنید.
- **پیوست فایل‌ها:**
  - **همه:** همهٔ فایل‌های پیوست‌شده به رکوردی که اعلان را آغاز کرده است می‌فرستد.
  - **از فیلد:** فایلی را از یک فیلد پیوست مشخص ارسال می‌کند.
    - **فیلد پیوست:** فیلدی را انتخاب کنید که فایل موردنظر در آن نگهداری می‌شود.

### اقدام‌های پس از اعلان

- **تنظیم ویژگی پس از هشدار:** پس از ارسال اعلان، مقدار یک فیلد را به‌روزرسانی می‌کند.
- **مقداری که باید تنظیم شود:** مقدار موردنظر برای فیلد مشخص‌شده را وارد کنید.

## روش‌های پیشنهادی

1. **اعلان‌ها را آزمایش کنید:** برای آزمودن اعلان‌های مبتنی بر تاریخ، دکمهٔ **دریافت هشدارهای امروز** را بزنید.
2. **شرط‌ها را دقیق بنویسید:** شرط‌ها را هدفمند تنظیم کنید تا اعلان‌های غیرضروری زیاد نشوند.
3. **در استفاده از الگوها دقت کنید:** پیام‌ها را روشن بنویسید و فقط اطلاعات مرتبط را بیاورید.
4. **فیلدهای گیرنده را بررسی کنید:** مطمئن شوید فیلدها نشانی ایمیل یا شمارهٔ تلفن معتبر دارند.
5. **سطح دسترسی را در نظر بگیرید:** گیرندگان باید اجازهٔ دسترسی به سندهای ارجاع‌شده در اعلان را داشته باشند.

## عیب‌یابی

- اگر اعلان ارسال نمی‌شود، بررسی کنید سند همهٔ شرط‌ها را برآورده می‌کند.
- برای ایمیل، درستی تنظیمات ایمیل را بررسی کنید.
- برای پیامک، مطمئن شوید تنظیمات پیامک پیکربندی شده‌اند.
- برای Slack، معتبر و فعال‌بودن نشانی URL وب‌هوک را بررسی کنید.
- گزارش‌های سرور را برای خطاهای مربوط به ارسال اعلان بررسی کنید.

## نکته‌های فنی

- اعلان‌ها به‌صورت ناهمگام پردازش می‌شوند تا بر کارایی سامانه اثر نگذارند.
- رویدادهای مبتنی بر تاریخ هر روز با یک کار زمان‌بندی‌شده بررسی می‌شوند.
- اعلان‌های رویداد سند، هم‌زمان با انجام اقدام مربوط آغاز می‌شوند.
- شرط‌ها و الگوها در محیطی محدودشده و با ملاحظات امنیتی ارزیابی می‌شوند.

با پیکربندی درست نوع سند اعلان، می‌توانید کاربران را از رویدادهای مهم آگاه کنید و ارتباطات برنامهٔ Frappe خود را خودکار سازید.
