## درخواست Web Form

**Web Form Request** یک پیوند خصوصی برای یک **Web Form** ایجاد می‌کند.

از آن وقتی استفاده کنید که فرم نباید کاملاً عمومی باشد، اما پاسخ‌دهنده باید بتواند بدون داشتن حساب کاربری آن را ارسال کند. برای نمونه، می‌توانید پیوند نظرسنجی رضایت مشتری را برای او بفرستید، مقدارهای مخصوص همان مشتری را از پیش در فرم قرار دهید و فیلدهای داخلی را از مرورگر پنهان نگه دارید.

## چه زمانی از آن استفاده کنیم؟

درخواست **Web Form Request** مناسب است اگر:

1. پاسخ‌دهنده باید فرم را از طریق پیوندی خصوصی باز کند.
2. ممکن است پاسخ‌دهنده حساب کاربری نداشته باشد.
3. فرم باید مقدارهای مخصوص همان پاسخ‌دهنده را در بر بگیرد.
4. سند مقصد به مقدارهای پنهانی نیاز دارد که نباید در صفحهٔ وب افشا شوند.

## ساخت درخواست

یک **Web Form Request** بسازید و **Web Form** مربوط به آن را انتخاب کنید. یک کلید سازگار با URL به‌طور خودکار ساخته می‌شود.

درخواست می‌تواند این مقدارها را تعیین کند:

- **Expires On:** تاریخ و زمان انقضای کلید درخواست.
- **Web Form Values:** مقدارهای JSONای که در Web Form نمایش داده می‌شوند و پاسخ‌دهنده می‌تواند آن‌ها را ویرایش کند.
- **Doc Values:** مقدارهای JSONای که هنگام ارسال فرم روی سند مقصد اعمال می‌شوند، اما به مرورگر فرستاده نمی‌شوند.

کلید درخواست در نشانی Web Form به‌کار می‌رود:

```text
/your-web-form-route/new?web_form_request_key=<key>
```

می‌توانید این نشانی را از فرم **Web Form Request** کپی کنید.

## اجباری‌کردن کلید

برای اجباری‌کردن کلید معتبر **Web Form Request**، گزینهٔ **Key required** را در **Web Form** فعال کنید.

اگر **Key required** فعال باشد و کلید معتبری ارائه نشود، Web Form باز یا ارسال نمی‌شود.

اگر **Login required** نیز فعال باشد، هر دو شرط اعمال می‌شوند: کاربر باید وارد حساب خود شده باشد و یک کلید درخواست معتبر ارائه کند.

## مقدارهای ازپیش‌پرشده و پنهان

برای فیلدهایی که باید پاسخ‌دهنده ببیند، از **Web Form Values** استفاده کنید. این فیلدها باید در جدول فیلدهای **Web Form** درج شده باشند.

برای فیلدهایی که باید در سند ایجادشده تنظیم شوند، اما پاسخ‌دهنده نباید آن‌ها را ببیند، از **Doc Values** استفاده کنید. این فیلدها باید در DocType مقصد وجود داشته باشند.

کلیدهای JSON باید از نام‌های فنی فیلدها استفاده کنند؛ برای نمونه `customer` یا `survey_source`.

نمونه:

```json
{
 "customer": "CUST-0001",
 "survey_source": "Partner CSAT"
}
```

## انقضا و استفاده

اگر **Expires On** تنظیم شده باشد، پس از آن تاریخ و زمان دیگر نمی‌توان از کلید درخواست استفاده کرد.

در یک Web Form با پاسخ تکی، پس از ارسال موفق فرم، درخواست به‌عنوان استفاده‌شده علامت‌گذاری می‌شود و به سند مقصدِ ایجادشده پیوند می‌خورد. اگر تنظیمات **Web Form** اجازه دهند، همین کلید بعداً برای ویرایش یا حذف آن پاسخ نیز قابل استفاده است.

اگر گزینهٔ **Allow multiple responses** در **Web Form** فعال باشد، می‌توان کلید درخواست را برای چند ارسال دوباره به‌کار برد و کلید به یک سند مقصد مشخص پیوند نمی‌خورد.

## تنظیمات مرتبط Web Form

- **Allow Multiple Responses:** اگر فعال باشد، یک کلید درخواست می‌تواند چند پاسخ را ارسال کند. در این حالت، **Web Form Request** نمی‌تواند **Reference Docname** داشته باشد، چون یک درخواست ممکن است چند سند ایجاد کند.
- **Allow Editing After ارسال:** اگر فعال باشد، کلید درخواستِ پیوندخورده به یک پاسخ می‌تواند همان پاسخ را باز کند و ویرایش کند.
- **Allow Delete:** اگر فعال باشد، کلید درخواستِ پیوندخورده به یک پاسخ می‌تواند آن پاسخ را حذف کند.
