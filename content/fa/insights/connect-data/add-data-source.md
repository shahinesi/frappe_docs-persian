## پیش‌نیازها

پیش از اتصال منبع داده، اطلاعات زیر را آماده کنید؛ در صورت نیاز از مدیر پایگاه داده بپرسید:

| فیلد | توضیح |
| --- | --- |
| میزبان | نشانی سرور؛ مانند <code>db.mycompany.com</code> یا <code>localhost</code>. |
| پورت | درگاه اتصال؛ برای نمونه <code>3306</code> برای MariaDB و <code>5432</code> برای PostgreSQL. |
| Database Name | نام پایگاه داده‌ای که می‌خواهید به آن وصل شوید. |
| Username | نام کاربری ورود. |
| Password | گذرواژهٔ ورود. |
| SSL (اختیاری) | مشخص می‌کند از اتصال امن استفاده شود یا نه. |

> **توجه:** برای افزودن پایگاه داده به‌عنوان منبع داده، باید نقش **Insights Admin** داشته باشید.

## شروع سریع: افزودن منبع داده

### گام 1: رفتن به منابع داده

در نوار کناری روی **Data Sources** و سپس **+ Add Data منبع** کلیک کنید. نوع پایگاه داده را انتخاب کنید.

### گام 2: واردکردن جزئیات اتصال

برای نمونه، هنگام اتصال به MariaDB این اطلاعات را وارد کنید:

- **عنوان**: نامی گویا؛ مانند «پایگاه دادهٔ عملیاتی».
- **میزبان**: نشانی سرور؛ مانند <code>localhost</code> یا <code>db.mycompany.com</code>.
- **پورت**: برای MariaDB معمولاً <code>3306</code> است و از پیش پر شده است.
- **Database Name**: نام دقیق پایگاه داده.
- **Username / Password**: اطلاعات ورود پایگاه داده.
- **استفاده از SSL**: اگر لازم است، این گزینه را فعال کنید.

### گام 3: افزودن و آزمایش اتصال

پس از تکمیل اطلاعات روی **Add Data منبع** کلیک کنید. Insights اتصال را ذخیره می‌کند، جدول‌ها را بارگذاری می‌کند و آن‌ها را برای پرس‌وجو در دسترس می‌گذارد.

## بارگذاری CSV یا Excel

این روش برای واردکردن سریع داده، مجموعه‌داده‌های کوچک یا آزمایش Insights بدون پایگاه داده مناسب است.

### روش بارگذاری

1. روی **+ Add Data منبع** و سپس **Upload CSV or Excel** کلیک کنید.
2. فایل را انتخاب کنید یا آن را بکشید و در محل مشخص‌شده رها کنید.
3. پیش‌نمایش داده را ببینید و ستون‌ها و نوع داده‌ها را بررسی کنید.
4. در صورت نیاز نام جدول را ویرایش کنید.
5. روی **Import Table** کلیک کنید.

### قالب‌های پشتیبانی‌شده

- CSV با پسوند <code>.csv</code>
- Excel با پسوند <code>.xlsx</code>

محدودیت اندازهٔ فایل 50MB است؛ برای اطلاع دقیق با مدیر سامانه هماهنگ کنید.

**نکته‌ها:**

- ردیف اول باید عنوان ستون‌ها باشد.
- نام ستون‌ها را ساده انتخاب کنید.
- از قالب تاریخ یکسان استفاده کنید.
- ردیف‌های خالی انتهای فایل را حذف کنید.

## پایگاه دادهٔ سایت (پیکربندی خودکار)

اگر Insights را روی همان سایت دیگر اپ‌های backend فرپ نصب کرده‌اید، Insights به‌طور خودکار به پایگاه دادهٔ سایت متصل می‌شود. در نتیجه داده‌های ERPNext، Frappe و اپ‌های سفارشی فوراً در دسترس قرار می‌گیرند.

**ویژگی‌ها:**

- به‌صورت خودکار پیکربندی می‌شود و همیشه فعال است.
- نیازی به اطلاعات ورود ندارد.
- همهٔ DocTypeها به‌شکل جدول در دسترس‌اند.
- پیوندهای رابطه‌ای از پیش پیکربندی شده‌اند.

### خطاهای متداول

#### اتصال رد شد (Connection refused)

میزبان و پورت را بررسی کنید.

#### دسترسی رد شد (Access denied)

نام کاربری و گذرواژه را بررسی کنید.

#### پایگاه داده ناشناخته است (Unknown database)

املای نام پایگاه داده را بررسی کنید.
