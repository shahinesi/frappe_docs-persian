> متن این صفحه ترجمه و اقتباسی از منبع بالاست و تحت شرایط CC BY-SA آن منبع بازنشر می‌شود (نسخه در سیاست منبع مشخص نشده است). این ترجمه مستقل و غیررسمی است.

Insights v3.50 نسخهٔ Insights v2، رابط قدیمی با پرس‌وجوها و داشبوردهای مستقل، را حذف می‌کند. پیش از به‌روزرسانی به v3.50، داشبوردهای v2 را با صفحهٔ **Migrate from v2** در Insights نسخهٔ v3.13 تا v3.15.1 به v3 منتقل کنید.

برای این کار عجله نکنید؛ می‌توانید تا هر زمان لازم است روی Insights v3.15 بمانید.

:::note[Frappe Cloud]
برای دریافت راهنمایی دربارهٔ مهاجرت، یک [تیکت پشتیبانی](https://frappe.io/support) ثبت کنید.
:::

### اگر یکی از این موارد دربارهٔ شما صدق می‌کند، این راهنما را دنبال کنید:

- **تیم شما هنوز از داشبوردهای v2 استفاده می‌کند.** با نقش Insights Admin وارد Insights شوید و در نوار کناری روی **Settings** کلیک کنید. اگر گزینهٔ **Migrate from v2** را می‌بینید، سایت شما داده‌های v2 دارد.
- **به‌روزرسانی به v3.50 با پیام «Insights v2 has been removed — update blocked» متوقف شده است.** در 30 روز گذشته کسی از داشبورد v2 استفاده کرده و آن داشبورد هنوز مهاجرت داده نشده است. این بررسی پیش از آن انجام می‌شود که Insights هرگونه داده‌ای را تغییر دهد.

اگر نیازی به داشبوردهای v2 ندارید، به بخش [به‌روزرسانی بدون مهاجرت](#update-without-migrating) بروید.

## گام 1: Insights را به v3.13 یا بالاتر ارتقا دهید

نسخهٔ Insights خود را پیدا کنید:

- **Private Bench:** گروه bench را در داشبورد باز کنید و سپس زبانهٔ **Apps** را باز کنید.
- **Public Bench:** سایت را در داشبورد باز کنید و سپس زبانهٔ **Apps** را باز کنید. نسخه در پیام commit مربوط به Insights است.
- **میزبانی‌شده توسط خودتان:** نسخه را از تاریخچهٔ commitهای Insights بررسی کنید.

اگر نسخه v3.13 یا بالاتر است، به گام 2 بروید.

اگر نسخه قدیمی‌تری دارید:

- **Frappe Cloud:** یک [تیکت پشتیبانی](https://frappe.io/support) ثبت کنید و درخواست دهید سایت به Insights v3.15.1 منتقل شود.
- **میزبانی‌شده توسط خودتان:** مراحل زیر را دنبال کنید.

### میزبانی‌شده توسط خودتان: دریافت نسخهٔ v3.15.1

دستور `bench update` آخرین نسخه را دریافت می‌کند که ممکن است v3.50 باشد. باید به‌جای آن tag نسخهٔ `v3.15.1` را دریافت کنید. از پوشهٔ bench این فرمان‌ها را اجرا کنید:

```bash
bench --site all backup --with-files
cd apps/insights
git fetch --tags
git checkout v3.15.1
cd ../..
bench setup requirements --python
bench build --app insights
bench --site all migrate
bench restart
```

:::caution
تا پیش از گام 3، `bench update` را اجرا نکنید. وقتی Insights روی یک tag است، `bench update` شاخهٔ نادرستی را دریافت می‌کند.
:::

اگر `bench update` پیش‌تر در بررسی v2 متوقف شده است، همین فرمان‌ها را اجرا کنید. سپس حالت تعمیر و نگهداری‌ای را که به‌روزرسانی ناموفق روشن گذاشته، خاموش کنید:

```bash
bench set-config -g maintenance_mode 0
bench set-config -g pause_scheduler 0
```

## گام 2: داشبوردها را مهاجرت دهید

برای این کار باید نقش **Insights Admin** داشته باشید.

1. Insights را باز کنید: `/insights` را به نشانی سایت اضافه کنید؛ برای نمونه `example.frappe.cloud/insights`.
2. در نوار کناری روی **Settings** و سپس **Migrate from v2** کلیک کنید. Insights داشبوردهای v2 را همراه وضعیت هرکدام فهرست می‌کند.
3. روی یک داشبورد کلیک کنید تا محتوای آن و تغییرات مهاجرت را ببینید.
4. یک داشبورد انتخاب و روی **Migrate** کلیک کنید. کارپوشه جدید را باز و با داشبورد v2 مقایسه کنید.
5. داشبوردهای دیگر را انتخاب و روی **Migrate** کلیک کنید.

| وضعیت | معنی |
| --- | --- |
| Ready to migrate | داشبورد بدون تغییر مهاجرت می‌کند. |
| Needs review | بعضی بخش‌ها بدون تغییر منتقل نمی‌شوند. برای دیدن موارد، روی داشبورد کلیک کنید. |
| Could not be read | Insights نمی‌تواند بخشی از داشبورد را بخواند. آن را جداگانه مهاجرت دهید تا خطا مشخص شود. |
| Could not migrate | مهاجرت ناموفق بود و چیزی را تغییر نداد. دوباره روی **Migrate** کلیک کنید. |
| Migrated | یک نسخهٔ v3 از داشبورد ساخته شده است. |

:::tip[امکان تکرار امن]
مهاجرت داشبوردهای v2 را تغییر نمی‌دهد. اگر داشبوردی را دوباره مهاجرت دهید، Insights از آن عبور می‌کند و ویرایش‌های شما در نسخهٔ v3 باقی می‌مانند.
:::

پس از هر مهاجرت، Insights تعداد نتیجه‌های هر پرس‌وجوی جدید را با نتیجه‌های v2 مقایسه می‌کند؛ برای نمونه «4 of 4 queries return the same numbers as v2». اگر نموداری اعداد متفاوتی نشان می‌دهد، روی داشبورد کلیک کنید و سپس **Open in v3** را انتخاب کنید.

Insights پرس‌وجوهای اسکریپتی، پرس‌وجوهای پرس‌وجو Store یا پرس‌وجوهای pivot را مقایسه نمی‌کند؛ این موارد را خودتان بررسی کنید.

- این صفحه 500 داشبورد v2 را که اخیراً تغییر کرده‌اند فهرست می‌کند. اگر سایت شما بیش از این تعداد داشبورد دارد، یک [تیکت پشتیبانی](https://frappe.io/support) ثبت کنید.
- در سایتی که خودتان میزبانی می‌کنید، مهاجرت با کارهای پس‌زمینه انجام می‌شود. اگر وضعیت تغییری نمی‌کند، مطمئن شوید workerهای bench در حال اجرا هستند.

## گام 3: به v3.50 به‌روزرسانی کنید

وقتی همهٔ داشبوردهای v2 را که می‌خواهید نگه دارید مهاجرت دادید، به‌روزرسانی کنید.

- **Frappe Cloud:** سایت را از داشبورد به‌روزرسانی کنید.
- **میزبانی‌شده توسط خودتان:** به شاخهٔ `version-3` برگردید و سپس به‌روزرسانی کنید:

```bash
cd apps/insights
git checkout version-3
cd ../..
bench update
```

به‌روزرسانی فقط برای داشبوردهای v2 متوقف می‌شود که در 30 روز گذشته استفاده شده‌اند و هنوز مهاجرت داده نشده‌اند. تعداد آن‌ها نمایش داده می‌شود. مهاجرتشان دهید و دوباره به‌روزرسانی کنید.

:::caution
داشبورد v2ای که در 30 روز گذشته استفاده نشده باشد جلوی به‌روزرسانی را نمی‌گیرد، اما به نسخهٔ جدید منتقل نمی‌شود. اگر می‌خواهید آن را نگه دارید، آن را هم مهاجرت دهید.
:::

## چه چیزهایی مهاجرت می‌کنند؟

هر داشبورد v2 به یک کارپوشه در v3 تبدیل می‌شود که همان عنوان و مالک را دارد. کارپوشه شامل این موارد است:

- پرس‌وجوهای داشبورد و پرس‌وجوهای پرس‌وجو Store که آن‌ها می‌خوانند.
- نمودارها، فیلترها و متن داشبورد با همان چیدمان.
- متغیرهای پرس‌وجوهای اسکریپتی.

Insights از منبع دادهٔ v3ای استفاده می‌کند که نامش با منبع دادهٔ v2 یکسان است. اگر چنین منبعی وجود نداشته باشد، Insights آن را با جزئیات اتصال v2 می‌سازد.

## چه چیزهایی مهاجرت نمی‌کنند؟

- **پرس‌وجوهای v2 که در هیچ داشبوردی نیستند:** برای نگه‌داشتن یک پرس‌وجو، پیش از مهاجرت آن را به داشبورد v2 اضافه کنید.
- **پیوندهای عمومی:** داشبورد عمومی v2 در v3 خصوصی می‌شود. آن را دوباره منتشر کنید.
- **اشتراک‌گذاری:** کارپوشه را دوباره با تیم به‌اشتراک بگذارید.
- **نوع نمودارهایی که v3 ندارد:** Insights این نمودارها را رد می‌کند و دلیل را می‌گوید.
- **گام‌های پرس‌وجویی که v3 ندارد:** Insights یا SQL اجراشده در v2 را نگه می‌دارد، یا گام را حذف و علت را اعلام می‌کند. اگر Insights فیلتری را حذف کند، نمودار ردیف‌های بیشتری از v2 نشان می‌دهد.

## به‌روزرسانی بدون مهاجرت

:::danger
پس از به‌روزرسانی دیگر نمی‌توانید پرس‌وجوها و داشبوردهای v2 را باز یا مهاجرت دهید. برای بازیابی آن‌ها باید نسخهٔ پشتیبان را در Insights v3.15.1 برگردانید و مهاجرت را همان‌جا انجام دهید.
:::

اگر به داشبوردهای v2 نیاز ندارید، `insights_allow_legacy_v2_upgrade` را در پیکربندی سایت روی `1` بگذارید. در این صورت به‌روزرسانی به v3.50 متوقف نمی‌شود.

- **Frappe Cloud:** یک [تیکت پشتیبانی](https://frappe.io/support) ثبت کنید و بخواهید این گزینه تنظیم شود.
- **میزبانی‌شده توسط خودتان:** این فرمان را برای هر سایت اجرا کنید:

```bash
bench --site <your-site> set-config insights_allow_legacy_v2_upgrade 1
```
