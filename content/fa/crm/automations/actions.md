اقدام‌ها گام‌هایی هستند که کار را انجام می‌دهند؛ مانند ارسال ایمیل، تغییر فیلد، واگذاری به کاربر یا تبدیل سرنخ. برای افزودن اقدام روی بوم **+** را بزنید. اقدام‌ها بر اساس برنامه‌ای که فراهمشان می‌کند در گروه‌های **CRM** و **هسته** قرار می‌گیرند.

فقط اقدام‌های سازگار با نوع سند خودکارسازی نمایش داده می‌شوند. برای نمونه، **تنظیم امتیاز سرنخ** فقط برای **سرنخ** (`CRM Lead`) ارائه می‌شود. برای یافتن سریع اقدام، در **جست‌وجوی بلوک‌ها** عبارت موردنظر را وارد کنید.

![جست‌وجوی اقدام‌های سرنخ در انتخاب‌گر گام](https://docs.frappe.io/files/crm-automations-picker-search.png)

بیشتر تنظیم‌های متنی از الگوهایی مانند `{{ doc.lead_name }}` پشتیبانی می‌کنند. برای جزئیات، [راهنمای شروع به کار](getting-started.md) را ببینید.

## اقدام‌های CRM

| اقدام | قابل استفاده برای | کارکرد |
|---|---|---|
| **ارسال ایمیل به سرنخ یا معامله** | سرنخ، معامله | به نشانی ایمیل ثبت‌شده در رکورد پیام می‌فرستد. |
| **اعلان در CRM** | سرنخ، معامله | در زنگ اعلان‌های CRM پیامی نشان می‌دهد. |
| **تنظیم امتیاز سرنخ** | سرنخ | به امتیاز سرنخ اضافه یا از آن کم می‌کند. |
| **تنظیم دمای سرنخ** | سرنخ | سرنخ را در یکی از رده‌های سرد، گرم یا داغ می‌گذارد. |
| **تبدیل سرنخ به معامله** | سرنخ | سرنخ را به معامله تبدیل می‌کند. |

### ارسال ایمیل به سرنخ یا معامله

ایمیلی به نشانی ثبت‌شده در سرنخ یا معامله می‌فرستد. ایمیل مانند پیامی که دستی می‌فرستید در فعالیت‌های رکورد ثبت می‌شود.

| تنظیم | مفهوم |
|---|---|
| **الگوی ایمیل** | الگویی برای موضوع و بدنهٔ ایمیل. الگوها مانند `{{ doc.first_name }}` به فیلدهای رکورد دسترسی دارند. |
| **موضوع** | اگر الگویی انتخاب نشده باشد استفاده می‌شود. |
| **پیام** | اگر الگویی انتخاب نشده باشد استفاده می‌شود. |
| **ارسال از طرف** | کاربری که ایمیل را می‌فرستد. برای استفاده از حساب ایمیل خروجی پیش‌فرض خالی بگذارید. |

باید الگویی انتخاب کنید یا موضوعی بنویسید. اگر رکورد نشانی ایمیل نداشته باشد، گام ناموفق می‌شود.

![ارسال ایمیل با الگوی خوشامدگویی سرنخ وب](https://docs.frappe.io/files/crm-automations-email-action-panel.png)

### اعلان در CRM

اعلانی را به زنگ اعلان‌های CRM کاربران انتخاب‌شده می‌افزاید. با انتخاب اعلان، سرنخ یا معامله باز می‌شود.

| تنظیم | مفهوم |
|---|---|
| **گیرندگان** | کاربرانی که باید مطلع شوند؛ همچنین می‌توانید **مالک سند** یا **مسئولان** را انتخاب کنید تا هنگام اجرا از روی رکورد تعیین شوند. |
| **اعلان** | متنی که در فهرست اعلان‌ها نشان داده می‌شود. |
| **پیام** | متن بلندتر و اختیاری اعلان. |

اگر کاربری که خودکارسازی با مجوزهای او اجرا می‌شود در میان گیرندگان باشد، او نیز اعلان می‌گیرد.

![اعلان CRM برای یادآوری به مالک سند](https://docs.frappe.io/files/crm-automations-notify-action-panel.png)

### تنظیم امتیاز سرنخ

عددی را به امتیاز سرنخ اضافه می‌کند؛ اگر عدد منفی باشد از امتیاز کم می‌شود.

| تنظیم | مفهوم |
|---|---|
| **مقدار** | امتیازی که باید اضافه یا کم شود؛ مانند `10` یا `-5`. |
| **دلیل** | اختیاری؛ همراه با تغییر ثبت می‌شود. |
| **کمینهٔ امتیاز / بیشینهٔ امتیاز** | محدودیت اختیاری؛ امتیاز از این بازه پایین‌تر یا بالاتر نمی‌رود. |

### تنظیم دمای سرنخ

**دمای** سرنخ را به **سرد**، **گرم** یا **داغ** تغییر می‌دهد.

### تبدیل سرنخ به معامله

سرنخ را به معامله تبدیل می‌کند و در صورت نیاز مخاطب و سازمان می‌سازد؛ مانند انتخاب **تبدیل به معامله** در خود سند سرنخ.

| تنظیم | مفهوم |
|---|---|
| **اگر قبلاً تبدیل شده است** | **برگرداندن رکورد موجود** (پیش‌فرض) از معاملهٔ قبلی سرنخ استفاده می‌کند؛ **ناموفق‌شدن** گام را متوقف می‌کند. |
| **مخاطب موجود** | اختیاری؛ به‌جای ساخت مخاطب تازه، معامله را به این مخاطب پیوند می‌دهد. |
| **سازمان موجود** | اختیاری؛ به‌جای ساخت سازمان تازه، معامله را به این سازمان پیوند می‌دهد. |
| **جایگزینی فیلدهای معامله** | اختیاری؛ مقدارهای سند تازه را به‌صورت JSON تعیین می‌کند؛ مانند `{"deal_owner": "{{ doc.lead_owner }}", "probability": 20}`. |

در بخش **پیشرفته** برای نتیجه نامی مانند `deal` بگذارید تا گام‌های بعدی روی معاملهٔ تازه کار کنند. برای نمونه، پس از آن **واگذاری به کاربر** را اضافه کنید و فیلد **رکورد** را روی `deal` قرار دهید.

## اقدام‌های هسته

این اقدام‌ها را Frappe Framework فراهم می‌کند و روی هر نوع سندی قابل استفاده‌اند.

| اقدام | کارکرد |
|---|---|
| **تنظیم مقدار فیلد** | مقدار یک یا چند فیلد رکورد را تنظیم می‌کند. |
| **افزایش مقدار فیلد** | به مقدار عددی یک فیلد اضافه می‌کند. |
| **ایجاد سند** | رکورد تازه‌ای از هر نوع می‌سازد. |
| **واگذاری به کاربر** | رکورد را به یک یا چند کاربر می‌سپارد. |
| **ارسال اعلان** | ایمیل یا اعلان میزکار می‌فرستد. |
| **فراخوانی وب‌هوک** | درخواست HTTP را به سامانهٔ دیگری ارسال می‌کند. |
| **اجرای اسکریپت** | اسکریپت سرور API را اجرا می‌کند. |

### تنظیم مقدار فیلد

یک **فیلد** و **مقدار** انتخاب کنید یا چند فیلد را هم‌زمان در **مقدارهای فیلد** با JSON تنظیم کنید؛ مانند `{"status": "Contacted", "priority": "High"}`. سپس رکورد ذخیره می‌شود و اعتبارسنجی‌های معمول آن اجرا می‌شوند.

### افزایش مقدار فیلد

یک فیلد عددی و **مقدار** را انتخاب کنید. برای کم‌کردن از مقدار منفی استفاده کنید. این اقدام هنگام به‌روزرسانی هم‌زمان رکورد در چند اجرا ایمن است.

### ایجاد سند

**نوع سند** و **مقدارهای فیلد** را با JSON تعیین کنید. برای نمونه، هنگام بردن معامله یک کار پیگیری بسازید:

```json
{
  "title": "Kick-off call with {{ doc.organization }}",
  "reference_doctype": "CRM Deal",
  "reference_docname": "{{ doc.name }}",
  "assigned_to": "{{ doc.deal_owner }}"
}
```

در بخش **پیشرفته** برای نتیجه نامی بگذارید تا گام‌های بعدی بتوانند روی رکورد ساخته‌شده کار کنند.

### واگذاری به کاربر

کاربران را در **واگذاری به** انتخاب کنید و در صورت نیاز **توضیح** واگذاری را بنویسید.

### ارسال اعلان

| تنظیم | مفهوم |
|---|---|
| **کانال** | **ایمیل** پیام ایمیل می‌فرستد؛ **سامانه** اعلان میزکار ثبت می‌کند. |
| **گیرندگان** | کاربرها، **مالک سند** یا **مسئولان**. |
| **الگوی ایمیل** | اختیاری و فقط برای ایمیل. |
| **موضوع / پیام** | اگر الگویی انتخاب نشده باشد استفاده می‌شود. |

برای اعلان‌دادن به کاربران درون CRM، به‌جای این اقدام از **اعلان در CRM** استفاده کنید.

### فراخوانی وب‌هوک

درخواستی را به سامانهٔ دیگری می‌فرستد؛ برای نمونه برای ارسال معاملهٔ برده‌شده به ابزار صورت‌حساب.

| تنظیم | مفهوم |
|---|---|
| **نشانی** | مقصد درخواست؛ می‌تواند الگو داشته باشد. |
| **روش** | `GET`، `POST` (پیش‌فرض)، `PUT`، `PATCH` یا `DELETE`. |
| **سرآیندها** | JSON اختیاری، مانند سرآیند مجوز دسترسی. |
| **بار داده** | بدنهٔ JSON اختیاری؛ می‌تواند الگو داشته باشد. |
| **مهلت (ثانیه)** | حداکثر `120`؛ مقدار پیش‌فرض `30` است. |

پاسخ با وضعیت `400` یا بالاتر گام را ناموفق می‌کند. اجرای آزمایشی درخواست را نمی‌فرستد و فقط گزارش آن را نشان می‌دهد.

> وب‌هوک برگشت‌پذیر نیست. اگر گام بعدی ناموفق شود، درخواست قبلاً فرستاده شده است.

### اجرای اسکریپت

یک **اسکریپت سرور** از نوع **API** را برای کارهایی اجرا می‌کند که اقدام‌های آماده پوشش نمی‌دهند. ابتدا اسکریپت را در میزکار بنویسید و بازبینی کنید؛ سپس آن را اینجا انتخاب کنید. اسکریپت‌های سرور باید در سایت فعال باشند.

## نتیجهٔ گام‌های قبلی

برخی اقدام‌ها مقدارهایی تولید می‌کنند که گام‌های بعدی با استفاده از نام گام می‌توانند از مسیر `context["steps"]` بخوانند:

| اقدام | مقدارهای تولیدشده |
|---|---|
| **تنظیم امتیاز سرنخ** | `old_value`، `new_value`، `delta` |
| **تنظیم دمای سرنخ** | `old_value`، `new_value` |
| **افزایش مقدار فیلد** | `old_value`، `new_value`، `delta` |
| **تبدیل سرنخ به معامله** | معاملهٔ تازه، `contact`، `organization` |
| **ایجاد سند** | رکورد تازه |
| **ارسال ایمیل به سرنخ یا معامله** | `communication` |
| **فراخوانی وب‌هوک** | `status_code`، `response` |

برای نمونه، اگر نام گام تنظیم امتیاز `score_reply` باشد، گام بعدی **اعلان در CRM** می‌تواند چنین متنی داشته باشد:

```
{{ doc.lead_name }} is now at {{ context.steps.score_reply.new_value }} points
```
